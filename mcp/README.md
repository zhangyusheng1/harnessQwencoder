# Model Context Protocol (MCP) Integration

This directory contains MCP (Model Context Protocol) integration files for accessing external design prototype services.

## Supported Platforms
- Pixso (https://pixso.cn/)
- Figma (planned)

## Configuration
MCP configuration is managed through:
- `harness/mcp-config.yaml` - Public configuration
- `config/secrets/mcp-secrets.yaml` - Private credentials (gitignored)

## Usage
The MCP tools enable 1:1 pixel-perfect UI implementation from design prototypes.
